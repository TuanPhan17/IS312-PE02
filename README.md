# 💻 IS312 – PE02: Personal Resume Website

## 📌 About This Project
For this assignment, I created a personal resume website using HTML and CSS. The website displays my work experience, technical skills, education, and contact information.

## ✨ Features
- Clean, light blue-and-white design
- Circular profile picture
- Expandable sections using HTML accordions
- Styled table displaying my technical skills
- Responsive layout for different screen sizes
- Contact links to my email, GitHub, and LinkedIn

## 🛠️ Technologies Used
- **HTML5** – Website structure and content
- **CSS3** – Styling, colors, and layout
- **GitHub Codespaces** – Development environment

## 🚀 How to Run
1. Open the project in GitHub Codespaces.
2. Open the terminal.
3. Run `python3 -m http.server 8000`.
4. Open port 8000 in your browser.

## 📚 What I Learned
I practiced using HTML and CSS to build and style a personal resume website. I also learned how to use accordions to make sections expandable and how to style a table using CSS.
